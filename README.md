# Applied Data Science & Machine Learning Portfolio

A collection of independent data analysis, data cleaning, and machine learning classification projects implemented in Python.

## Projects Included

1. **Global Population Distribution Analysis**
   - **Tools:** Pandas, Seaborn, Matplotlib
   - **Description:** Analyzed World Bank demographic indicators, creating categorical bar charts of regional country distributions and continuous population size histograms.

2. **Titanic Exploratory Data Analysis (EDA)**
   - **Tools:** Pandas, Seaborn
   - **Description:** Performed data cleaning, handled missing values, and conducted exploratory analysis to uncover survival correlations based on age, gender, and passenger class.

3. **Bank Marketing Decision Tree Classifier**
   - **Tools:** Scikit-Learn, Pandas, Seaborn
   - **Description:** Built and evaluated a supervised decision tree classifier to predict customer term deposit subscriptions, visualizing confusion matrices and tree architecture.

4. **Social Media Sentiment Analysis**
   - **Tools:** Pandas, Seaborn
   - **Description:** Analyzed public opinion patterns across various brands and digital topics, breaking down sentiment trends (Positive, Negative, Neutral, Irrelevant).

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
## 🚀 Future Roadmap & Planned Extensions
This repository serves as a modular playground for data science challenges. Future expansions planned for this project include:
* **Advanced NLP:** Integrating TF-IDF and transformer-based embeddings (BERT/DistilBERT) for deep social media sentiment classification.
* **Unsupervised Learning:** Adding K-Means clustering and PCA dimensionality reduction notebooks for customer segmentation datasets.
* **Time Series Forecasting:** Implementing ARIMA and Prophet models for economic and financial trend prediction.
* **Production Deployment:** Building an interactive web dashboard using Streamlit to deploy these models locally.
